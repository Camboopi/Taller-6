Descripción:

Aplicación GUI en Java Swing y Java2D para gestionar un diario personal de restaurantes. Que permite explorar restaurantes registrados, agregar nuevos indicando su ubicación en un mapa interactivo y visualizar gráficos 2D con los restaurantes visitados o ya guardados

Cómo Ejecutar

Desde Eclipse

1. Ve a File -> Import -> General -> Existing Projects into Workspace.

2. Selecciona la carpeta ‘Taller Swing Restaurantes Esqueleto’

3. Ejecuta la clase  ‘VentanaPrincipal.java’ 
   (src/uniandes/dpoo/swing/interfaz/principal/VentanaPrincipal.java)

Desde VS Code

1. Abre la carpeta ‘Taller Swing Restaurantes Esqueleto’

2. Abre ‘VentanaPrincipal.java’ y haz clic en Run o F5
